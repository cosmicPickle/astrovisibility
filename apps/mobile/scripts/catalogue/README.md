# Offline catalogue pipeline

Astrovisibility ships a deterministic catalogue generated from pinned local
inputs. Runtime catalogue access never downloads astronomy data.

## Inputs and attribution

- `openngc-v20260501-ngc.csv` and
  `openngc-v20260501-addendum.csv` are from OpenNGC release `v20260501`, commit
  `36cb178a0f69dba8bfc03a99c10512831edf1c6b`.
- `OPENNGC-CC-BY-SA-4.0.txt` is the upstream licence. The transformed catalogue
  remains attributed to the OpenNGC contributors under CC BY-SA 4.0.
- `caldwell-2026-08-19.csv` is a reviewed factual cross-reference of the
  Astronomical League's 109-object Caldwell Program Object List. It maps list
  membership to the pinned OpenNGC identities and records composite aliases.

The OpenNGC interpretation treats M102 as a duplicate of M101. The runtime data
therefore contains all 110 Messier designations across 109 physical records,
which prevents an alias from becoming a duplicate sky target.

## Refreshing data

Do not silently replace the pinned inputs. Review the new OpenNGC tag, commit,
licence and schema, then update the constants and source files together. Review
every unresolved duplicate and Caldwell mapping before accepting output.

From the repository root:

```powershell
pnpm --filter @astrovisibility/mobile catalogue:generate
pnpm --filter @astrovisibility/mobile catalogue:check
pnpm --filter @astrovisibility/mobile test -- --runTestsByPath scripts/catalogue/catalogueImporter.test.ts
```

The generator writes a compact runtime catalogue plus a readable validation
report and licence/provenance manifest. The check command rebuilds in memory and
compares every generated byte. Generated files must be committed with their
inputs and importer changes.
